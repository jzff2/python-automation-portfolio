What this is

A repository of small tools that were actually delivered, then collected with tests and documentation added. No code was written specifically as a demo. Each module has a clear input/output contract, keeps its parameters in config, and can be run, tested and replaced on its own.

The working loop is the one a written brief describes: brief → diff → tests → a short plain-English note stating what changed, how it was tested, and what remains.

Test result

Run with python run_tests.py — no pytest, no third-party packages. Each test copies the source into a temporary sandbox and invokes the real CLI in a subprocess, so the source needs no modification and no runtime data lands in the repository.

First run was 20/21. test_show_without_filter_does_not_crash found a genuine bug: the command dispatcher loaded configuration unconditionally, so a pure query command raised FileNotFoundError in a directory without a config file. The fix changed only the dispatcher; every business function is untouched, and the README records the difference between that copy and the production copy.

Engineering findings, with reproduction notes

  • Choosing the desktop background layer on Windows 11: this machine has more than twenty top-level WorkerW windows. The usual heuristic — pick the one without a SHELLDLL_DefView child — selects an unrelated window. The reliable rule is to select the WorkerW whose parent is Progman (here 68314). Verified: resulting window rect=(0,0)-(1920,1080), sitting behind desktop icons.
  • pywebview 6.2.1: the Window object exposes no native_window, and the loaded event did not fire under this configuration. The HWND is found by enumerating windows by title, and reparenting runs in a polling thread.
  • Silent process death: an Explorer restart destroys the WebView2 parent window and kills pythonw without a traceback. A supervisor restarts the renderer after three seconds; a marker file makes the quit hotkey exit both processes. Verified by window-tree enumeration and a debug log (all fish_pet processes reach zero).
  • 64-bit HWND: ctypes argtypes/restype are declared explicitly; wintypes.LRESULT does not exist and is replaced with ctypes.c_longlong.
